# BrainVibe — Personal Wealth & Trading Intelligence

BrainVibe is a personal finance and trading companion designed for Indian retail investors, wealth builders, and traders. Originally migrated and rewritten from Flutter into a modern, responsive React + TypeScript + Tailwind CSS web application.

## Key Features

- **Networth Tracker & Growth Analytics**: Real-time aggregated networth with dynamic portfolio area curves, asset breakdown, and liquidity tracking.
- **Goal Planner**: Active and completed goal tracking with target calculations (Weekly, Monthly, Yearly installments) and contribution transaction logs.
- **Deep Insights**: Monthly cashflow comparisons, risk indicators, spending velocity diagnostics, and category-wise distributions.
- **Live Curated News**: Curated financial intelligence across Indian business, tech, and crypto, with article reader modal and bookmarks.
- **Bank Accounts & Income**: Multi-bank account manager with real balance tracking, automated UPI/net-banking linking, and income stream categorization.
- **Expense Tracker & Visual Reports**: Day-wise expenditure tracking, multi-category distribution charts, and run-rate diagnostics.
- **Credit Card Manager**: Visual metallic card representations (Visa, Mastercard, RuPay), credit limit utilization safety indicators, and bank-linked one-tap bill payments.
- **Tradebook**: Trading journal for Intraday and Swing setups with equity curve visualization, risk-to-reward ratio calculation, and capital deposit/withdrawal ledger.
- **Market Watch**: Real-time Indian equity movers, global index trackers (Nifty, Sensex, Nasdaq, S&P 500, Nikkei), and live INR cryptocurrency spot valuations.
- **BrainVibe Coins & Pro**: Daily check-in rewards, referral links, gift voucher store, and Pro membership tiers.
- **Security & QPIN**: Quick 4-digit PIN lock/unlock sequence and biometric toggle to protect sensitive financial records.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 with custom neumorphic tokens (`#121212`, `#181818`, `#ffcf07`, `#46AA03`)
- **Visuals & Charts**: Recharts & Lucide Icons
- **Persistence**: Encrypted local state cache (`localStorage`) with pre-seeded demo records
